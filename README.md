#  NEXUS: RESSONÂNCIA

Jogo de reflexo e velocidade desenvolvido em **Python + Flet**.

##  Sobre o projeto

O objetivo é acertar os alvos antes que o tempo acabe, acumulando pontos e combos enquanto mantém sua estabilidade.

O jogo possui:

- 🎯 Sistema de pontuação e combo
- ⏱️ Cronômetro e dificuldade progressiva
- ❤️ Sistema de estabilidade
- 🏆 Níveis e condição de vitória
- ⏸️ Sistema de pausa
- 🔄 Opção de jogar novamente
- 📱💻 Interface responsiva para celular e computador

## 🛠️ Tecnologias

- Python 🐍
- Flet
- Asyncio
- Git/GitHub

## ▶️ Como executar

Instale o Flet:

```bash
pip install flet

Execute:

python main.py

Para executar no navegador:

flet run --web main.py
